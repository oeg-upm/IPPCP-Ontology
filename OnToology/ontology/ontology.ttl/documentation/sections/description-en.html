The Emissions Inventory Ontology: Description back to ToC

The **Emissions Inventory Ontology (EIO)** provides a semantic model for representing emission assessments together with the contextual information required to interpret them. It enables emission values to be associated with a specific indicator, geographical feature, reporting period, emission sector, numerical value, and unit of measurement. The ontology is centred on the class [s4city:KeyPerformanceIndicatorAssessment](https://saref.etsi.org/saref4city/KeyPerformanceIndicatorAssessment), which represents an individual assessment of an emission-related key performance indicator. Each assessment can be connected to the indicator being quantified through [s4city:quantifiesKPI](https://saref.etsi.org/saref4city/quantifiesKPI), to the corresponding geographical feature through [s4city:refersToFeature](https://saref.etsi.org/saref4city/refersToFeature), and to its reporting period through [s4city:refersToTime](https://saref.etsi.org/saref4city/refersToTime). The numerical result of an assessment is represented using [saref:hasValue](https://saref.etsi.org/core/hasValue), while its unit of measurement is specified through [saref:isMeasuredIn](https://saref.etsi.org/core/isMeasuredIn). The assessment is also related to an emission sector through [eio:refersToSector](#refersToSector). Emission sectors are represented by the class [eio:Sector](#Sector). These sectors are organised hierarchically using [skos:broader](http://www.w3.org/2004/02/skos/core#broader), allowing a sector to be connected to broader categories and enabling the representation of direct and indirect subsectors. The geographical context of an emission assessment can be represented through concepts such as [s4city:City](https://saref.etsi.org/saref4city/City), [s4city:District](https://saref.etsi.org/saref4city/District), and [eio:Cell](#Cell). The `eio:Cell` class supports the representation of spatial grid cells used in geographically disaggregated emission inventories. Temporal information is represented using concepts from [OWL-Time](https://www.w3.org/TR/owl-time/). Reporting periods can be modelled as [time:DateTimeInterval](http://www.w3.org/2006/time#DateTimeInterval) instances, described through [time:DateTimeDescription](http://www.w3.org/2006/time#DateTimeDescription), and associated with a calendar year through [time:year](http://www.w3.org/2006/time#year). EIO reuses terms from established ontologies and vocabularies to improve interoperability: * [SAREF](https://saref.etsi.org/) for values and units of measurement. * [SAREF4CITY](https://saref.etsi.org/saref4city/) for KPI assessments, geographical features, and temporal references. * [OWL-Time](https://www.w3.org/TR/owl-time/) for reporting periods and temporal descriptions. * [SKOS](https://www.w3.org/TR/skos-reference/) for the hierarchical organisation of emission sectors. * [QUDT](https://qudt.org/) for standard units of measurement.
